# 21st.dev building blocks

One real 21st.dev component per building block, chosen for an Apple-white, data-driven projector stage. Each source is saved as a REFERENCE copy in `design/21st/` with a header that gives the author, the URL and id, the licence and the adaptation notes. These files are not wired in. `tsconfig.json` only includes `src/`, so they never build.

How they were found: `mcp__21st__search` for every block, `mcp__21st__get_inspiration` for the ring, chart, countdown and steps, and `mcp__21st__get_component` for the picks and for any runner-up that had a real chance (2-3 candidates per block). Date: 2026-10-24.

Rule for wiring: re-implement each pick in `src/stage/kit/` against `palette.ts` and `index.css`, and do not paste it. Every live number keeps `data-src` and `data-val` (see `qa/README.md`). No new npm packages: every pick runs on what is already installed (motion, recharts, @phosphor-icons/react).

## Licence note

Kokonut UI (the activity ring) states MIT in its source. The shadcn/ui chart primitives are MIT. The other picks carry no licence header. They are published on the public 21st.dev registry for installing through the shadcn CLI, but that is not a licence. So they are kept as references and re-implemented in our kit, with the credit line in each kit file.

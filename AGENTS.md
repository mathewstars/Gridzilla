# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- The team pushes straight to `main` all day; keep changes to `platform/gridzilla.py` small and additive and rebase often. `platform/registry.yaml` is generated by `tools/gen-vienna.py`.
- Never call the live platform, the public broker or the team LLM gateway from dev work: they drive a real battery and heat pump. Run locally (platform `GZ_PORT`, local mosquitto, `agent/sim-agent.js` with `GZ_PLATFORM`/`GZ_BROKER`), see README *Quickstart*.
- Grid time runs `GZ_SIM_X` faster than real time (`sim_hour()`); autopilot, envelope and weather `grid_view` times are grid hours/minutes.
- Tests are offline stdlib unittest: `cd platform && python3 -m unittest discover -s tests` (fixtures in `platform/tests/fixtures/`).

## Maintaining this file

Keep this file for knowledge useful to almost every future agent session in this project.

Prefer rewriting or pruning existing entries over appending new ones.
When updating this file, preserve this bar for all agents and keep entries concise.
